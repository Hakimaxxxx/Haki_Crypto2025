## 📝 Adding New Documentation

When creating new documentation:
1. Place `.md` files in this `docs/` directory
2. Use descriptive filenames (e.g., `FEATURE_NAME_GUIDE.md`)
3. Update this README with a link and brief description
4. Follow existing formatting conventions

## 🗂️ File Naming Convention

- `FEATURE_NAME_GUIDE.md` - Feature implementation guides
- `ISSUE_RESOLUTION_YYYY-MM-DD.md` - Issue fixes with dates
- `CHANGELOG_YYYY-MM-DD.md` - Version changelogs
- Core docs use simple names (Architecture.md, Development.md, etc.)
